# 📊 داشبورد تحلیل داده | Data Analytics Dashboard

یک داشبورد وب ساده برای تحلیل داده: فایل Excel خود را بارگذاری کنید، داده‌ها را ببینید، نمودار بسازید و میانگین و آمار توصیفی را بررسی کنید. تمام پردازش‌ها در مرورگر شما انجام می‌شود و هیچ داده‌ای به سروری ارسال نمی‌شود.

## ✨ امکانات | Features

- **بارگذاری فایل** — Excel (xlsx/xls) و CSV، با انتخاب فایل یا کشیدن‌ورهاکردن، به‌همراه یک مجموعه‌داده نمونه
- **مشاهده داده‌ها** — پیش‌نمایش جدولی همراه با جست‌وجو و فیلتر
- **نمودارساز** — نمودار میله‌ای، خطی، پراکندگی، دایره‌ای، هیستوگرام و جعبه‌ای
- **آمار توصیفی** — میانگین، انحراف معیار، کمینه، بیشینه و چارک‌ها برای هر ستون عددی
- **تحلیل‌های بیشتر** — شمارش مقادیر و مقادیر گمشده
- **خروجی** — Excel، CSV، تصویر نمودار و گزارش PDF
- **رابط فارسی (RTL)** — با حالت تاریک/روشن و نمایش واکنش‌گرا در موبایل و دسکتاپ

## 🚀 نحوه استفاده | How to Use

هیچ نصب یا build لازم نیست؛ پروژه را با یک سرور محلی اجرا کنید:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید:

1. فایل Excel یا CSV خود را بارگذاری کنید (یا از مجموعه‌داده نمونه استفاده کنید).
2. داده‌ها را در پیش‌نمایش جدولی ببینید و در صورت نیاز جست‌وجو و فیلتر کنید.
3. از منوی کناری، بخش «نمودارساز» را باز کنید و با انتخاب نوع نمودار و ستون‌ها، نمودار بسازید.
4. میانگین و سایر آماره‌ها را در بخش «خلاصه آماری» ببینید.

## 🛠️ فناوری‌ها | Technologies

- **Vanilla JavaScript (ES6+)** — بدون فریم‌ورک و بدون build
- **HTML5 / CSS3** و **Tailwind CSS** (نسخه محلی)
- **[Plotly.js](https://plotly.com/javascript/)** — رسم نمودارها
- **[SheetJS](https://sheetjs.com/)** — خواندن و نوشتن فایل Excel
- **[PapaParse](https://www.papaparse.com/)** — خواندن فایل CSV

تمام کتابخانه‌ها به‌صورت محلی در `libs/` قرار دارند و پروژه کاملاً آفلاین کار می‌کند.
